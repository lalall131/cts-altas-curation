# Privacy and release review

This release was prepared as a publication supplement from the local CTS-Atlas curation skill.

The release was checked for and does not contain:

- Windows user names or home-directory paths;
- desktop, temporary-folder, or project-local file paths;
- email addresses, account names, passwords, API keys, or access tokens;
- unpublished sample identifiers or private study metadata;
- raw sequencing files or downloaded data.

Database accession examples such as GEO, SRA, ENCODE, and NGDC identifiers are scientific provenance fields, not personal information. Terms such as `private metadata` in the decision rules describe a possible database status and are not user-identifying data.

Before public deposition, the authors should replace the generic group author in `CITATION.cff`, add the final DOI and repository URL, and select the license required by the target journal.
